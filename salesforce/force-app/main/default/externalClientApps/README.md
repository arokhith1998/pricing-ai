# External Client App metadata goes here (retrieved, not hand-authored)

The Pricekeel External Client App (ECA) is the OAuth app customer orgs install.
It is intentionally **not** committed as a hand-written XML file, because its
consumer key and secret are generated by Salesforce when the app is created and
must not live in source control.

## How this directory gets populated

1. Create the ECA once in your durable source org with distribution state
   `Packaged` and the OAuth settings in
   `docs/ops/salesforce-integration-runbook.md` (callback
   `https://www.pricekeel.com/api/salesforce/oauth/callback`, scopes `api` and
   `refresh_token`/`offline_access`, PKCE required, no `full`).
2. Retrieve it into this project:

   ```bash
   sf project retrieve start \
     --metadata "ExternalClientApplication:Pricekeel" \
     --target-org <source-org-alias>
   ```

   That writes the `ExternalClientApplication`, `ExtlClntAppOauthSettings`,
   `ExtlClntAppGlobalOauthSettings`, and `ExtlClntAppOauthConfigurablePolicies`
   files into `force-app/main/default/`. Review them before committing, and
   confirm no consumer secret is present in the retrieved source (it should not
   be; the secret stays in the org and in Vercel env).

See `docs/ops/salesforce-2gp-packaging.md` for the full package build.
